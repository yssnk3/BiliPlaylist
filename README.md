# BiliPlaylist 🎵

> 将 TXT 歌单中的歌曲自动搜索并收藏到你的 Bilibili 收藏夹。

## 简介

BiliPlaylist 是一个纯前端工具，帮助你一键将歌单（TXT 格式）中的歌曲批量收藏到 Bilibili。你只需上传歌单文本，工具会自动解析歌曲名称，生成一段自动化脚本，在 Bilibili 控制台运行即可完成批量收藏。

## 快速开始

### 1️⃣ 准备歌单文本

访问 **[music.unmeta.cn](https://music.unmeta.cn)**，粘贴你的歌单链接，导出为 TXT 格式的纯文本文件。

或者手动整理一个每行一首歌曲的 `.txt` 文件（支持常见格式如 `[03:21] 歌曲名`、`1. 歌曲名.mp3` 等）。

### 2️⃣ 解析歌曲

1. 打开 [`BiliPlaylist.html`](./BiliPlaylist.html)（直接用浏览器打开即可，无需任何后端）
2. 上传歌单 TXT 文件
3. 工具会自动解析并列出识别的歌曲列表
4. 你可以编辑、删除或确认每首歌曲

### 3️⃣ 生成并运行脚本

1. 点击 **「生成全自动脚本」**
2. 点击 **「复制代码」**
3. 打开 [Bilibili](https://www.bilibili.com) 并确保已登录
4. 按 `F12` 打开开发者工具 → 切换到 **Console（控制台）**
5. 粘贴代码并回车运行
6. 在弹出的对话框中选择目标收藏夹，输入其数字 ID 即可

> ⚠️ 请允许浏览器弹出窗口（`prompt` 弹窗用于选择收藏夹）。

## 功能特性

- **📄 纯离线解析** — 无需 API Key，不依赖任何 AI 服务，所有解析在浏览器本地完成
- **🔧 智能清洗** — 自动去除时间戳、编号、文件后缀、杂项标注（MV/Lyrics 等）
- **✏️ 歌曲编辑** — 识别后支持逐条编辑或删除，灵活调整搜索词
- **🤖 全自动脚本** — 生成的脚本自带 Wbi 签名、MD5 等依赖，开箱即用
- **📦 单 HTML 文件** — 无需安装，无需构建，下载即用

## 技术说明

- 纯前端实现，基于 **React 18** + **Tailwind CSS**，全部打包在一个 HTML 文件中
- 生成的脚本在 Bilibili 控制台执行，通过官方 API 完成搜索和收藏操作
- 脚本包含完整的 Wbi 签名算法和 CSRF 校验，兼容 Bilibili 最新接口

## 注意事项

- 运行脚本时请确保已在 Bilibili 登录
- 可在脚本生成面板调整**请求间隔**（2s / 3s / 5s），避免请求过快被限流
- 如果某首歌未搜到结果或收藏失败，脚本会跳过并继续处理下一首
